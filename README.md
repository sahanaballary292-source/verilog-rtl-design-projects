# verilog-rtl-design-projects
A collection of Verilog HDL and RTL design projects developed while learning digital,FSMs,counters,ALU,barrel shifter,and UART communication.
## Digital Calculator

An 8-bit digital calculator designed using Verilog HDL.

### Operations
- Addition
- Subtraction
- Multiplication
- Division

### Features
- 8-bit inputs
- 16-bit result output
- 2-bit opcode for operation selection
- Division-by-zero error detection

### Files
- [digital_calculator.v](digital_calculator.v)– Verilog RTL design
- [digital_calculator_tb.v](digital_calculator_tb.v)– Testbench
